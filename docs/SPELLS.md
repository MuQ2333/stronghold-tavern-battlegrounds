# 法术操作说明

## 预览

局外点击“法术预览”，可按等阶筛选、搜索名称或效果、选择法术查看详情。不入池法术不在预览列表中显示。说明文本以当前游戏中的预览和详情为准。

## 购买与施放

调度中心使用独立法术商品栏。购买后的法术进入整备区，拖放到合法目标施放：

| 目标类型 | 放置位置 |
| --- | --- |
| 无指定干员的法术 | 战场上的任意普通格，无需场上已有干员 |
| 指定干员的法术 | 满足法术条件的目标干员 |
| 支援 | 空闲地面格，放置法术标记；战斗开始时部署星熊 |

目标不合法、资源不足或超过法术自己的使用次数限制时不会成功施放。具体次数、费用和效果看法术说明。

## 与策略互动

身份揭晓永久替换策略，阮大师每回合在两个候选技能中临时选择。两者与新增英雄、单人模式和法术开关共同适配，候选条件见[技能池说明](HERO-POWER-POOLS.md)。

开发者需要查看智慧球结果、库存语义和实现细节时，见[随源码安装的法术技术文档](../mod/payload/docs/SPELLS.md)。
