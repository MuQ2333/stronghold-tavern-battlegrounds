基础酒馆模组0.2.3，仍适配原版卫戍协议v0.3.0（c24e17eec3af1e6dedfa9935a6d15245cf2f4586），需要Node.js22+。

修复官方完整／精简玩家发布包缺少开发文档、测试文件时，被旧安装器误报“文件与适配上游不一致：docs/ARCHITECTURE.md”的问题。不是要求用户补齐开发文件或重装原游戏。

自动安装只写运行文件与素材，保留原游戏中的开发文档、测试和维护工具；运行代码仍严格校验，真实冲突会在写入前停止。游戏内容、界面和素材与0.2.2相同。

下载`Tavern-Battlegrounds-0.2.3-Full.zip`并完整解压，Windows运行`Import.cmd`，Linux运行`bash install.sh <游戏目录>`。若旧版仅预检报错、没有安装成功，直接用新包重试即可；已成功安装旧版的用户先卸载再安装。

本次使用实际官方0.3.0精简发布ZIP及固定提交源码归档分别验收；完整包与精简包共用官方文件筛选规则。GitHub与网盘使用同一份Full.zip和SHA256SUMS.txt。个人服务器整合分享包是独立分发，本次未改其玩法或部署。
