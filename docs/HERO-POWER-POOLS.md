# 身份揭晓与阮大师的策略技能池

本表对应英雄模组0.1.10的29名英雄及整合版新增阮大师，共30名。策略内容由独立包同步，整合补充在`mods/tavern-heroes.json`；候选政策在`shared/heroPowerPools.js`和`shared/spellBands.js`。

暴雪[21.2说明](https://news.blizzard.com/en-us/article/23712592/21-2-patch-notes)给出阮大师每回合从两个新技能中选择的基础规则；[28.6.2说明](https://news.blizzard.com/en-us/article/24056185/28-6-2-patch-notes)明确弗洛格尔技能移出其技能池。公开说明没有提供本版所有英雄对应的完整技能池、精确权重及所有回合门槛，不能将下表称为原版完整复刻。未被资料确定的适配标为[ASSUMED]，后续可按维护者决定调整。

原生策略按维护者确认的33个加入、7个排除，并检查模式、当前策略、队友、等级和未来触发条件。原生一次性开局奖励进入阮大师临时池时仅第1回合有效；定点奖励须在当前回合可触发。只在将来回合生效的事件不会提前发放。英雄开关关闭时不提供移植英雄；法术关闭时四名依赖法术的英雄均被过滤。

## 替换与结算

身份揭晓最多提供三个不同策略，永久替换当前技能；阮大师每回合最多提供两个不同策略，所选技能仅本回合生效。候选去除当前策略、队友占用策略及阮大师上回合使用的策略；不足时缩减数量。[ASSUMED] 合法候选等权抽取，不假定暴雪的隐藏权重。

临时技能在下一回合收入和调度中心刷新前到期。对外英雄身份仍为阮大师，元游戏和战斗输入使用实际选中的策略，原生盟约、购买、出售、升级及战斗技能沿相同事件链工作。选中后只补执行新策略的本回合开始事件，不重放普通收入、驻防或其他角色的回合开始。未确认选择时，在休整期结束前沿用现有默认选择规则。

替换清空未兑现的旧策略进度；生命、资金、已获层数、已赚取的后续资金、手牌与锁定卡保留。玛维的已获得锁定卡继续按卡本身的解锁时间解锁；不能凭换技能清除锁定。塞纳留斯已付费购买的永久收入保留。身份揭晓不会丢弃尚待领取的英雄发现：先领完既有发现后再选择替换。辛达苟萨的商品位数在替换时恢复或缩减，不额外刷新装备与法术。永久换入阮大师后立即提供本回合二选一。

验证见`test/nguyen.test.js`、`test/ui/nguyen.e2e.test.js`及现有英雄、法术、战斗结果验证。完整原生golden 287场景保持一致。
