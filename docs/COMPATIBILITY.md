# 社区模组共用测试

基线：原版 0.2.6，酒馆整合模组 0.1.0。兼容测试在独立副本进行。

| 模组 | 来源与固定版本 | 开关 |
| --- | --- | --- |
| 多人房间 | secret-c/stronghold-protocol-plugins，sp-mp 1.2.1，9ac813a5292dd30a1c48d9f9ee0d5a9240a33d31 | 房主在建房或等待室设置；关闭恢复 4 席，开启选 8/12 席 |
| 伤害看板 | jingjiangze，dmg-board 1.0.0 | 玩家独立开关；在最终结算显示各玩家数据 |
| 局内聊天 | 纸飞机，chat-bubble 1.0.0 | 玩家独立开关；关闭后不挂载、不显示聊天 |

两份界面包来自 [模组目录](https://github.com/XiaMo233M/Stronghold-Protocol-Forge-Mods)，固定提交 c848107e02acfcc367e1ed551b798b46c5cea1e5；原包元数据、README、来源说明保留在 public/community。它们仍各自提供 mount/unmount，兼容层只提供所需的界面宿主、消息和开关，不引入原模组平台。

多人部分按源插件与当前酒馆版本做三方合并。已修复相互覆盖导致英雄目录／法术库存逻辑丢失的冲突，补齐源插件遗漏的 capacity 协议。保留酒馆版本的装备合成库存处理。额外机变分页和卡池扩容沿用源多人插件；四人原生基准不变。

源 sp-mp 附带的客户端面板按我方干员掉血累计数字，不是输出伤害，本兼容包不启用它。dmg-board 仅展示服务端已有结算统计，不能当作实时逐干员 DPS 面板。

聊天适配为 community.chat 专用消息；同房真人才能发送，昵称由服务器填写，120 字限制，250ms 发送间隔。界面用 textContent 防止 HTML 执行，中文输入法候选确认不会误发送。关闭开关卸载监听和界面。

多人开关不能在已有第 5 席以上玩家时强行关闭；须先由玩家自行离房，防止缩容踢人。开始对局后容量与玩法开关锁定。

验证包括 4/8/12 人与法术、英雄开关的 12 组流程，12 个真实 WebSocket 客户端，8/12 人真实战斗模拟，界面开关和窄屏测试。测试报告与明确限制随发布包提供。真实远程服务器和安卓 APK 未以这些测试替代验收。
