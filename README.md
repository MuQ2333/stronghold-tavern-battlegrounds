# 卫戍协议：酒馆战棋（本地测试版）

当前本地测试版 **0.2.4-beta.2** 基于 [卫戍协议 0.3.3](https://github.com/sganggs/Stronghold-Protocol/tree/v0.3.3)，是非官方、非商业同人版本。包含酒馆模式、法术、策略与工坊导入；本版本仍在测试，玩法与数值可能调整。

## 本地使用

下载另行提供的 Windows 本地测试包，完整解压后双击「启动游戏.bat」。包内自带运行环境与素材，不必另装 Node.js；默认仅在本机访问。进入房间后可选择启用酒馆模式。包内「README-开箱即用.md」有详细说明。

启动后可在浏览器打开 `http://localhost:3000/studio/`，预览并导入 Forge 工坊包。请查看导入报告：英雄能力、独立法术商店及部分 0.21 内容已适配，但并非所有 Forge 玩法和服务端模块都已实现。默认入口使用脚本沙箱，受信任脚本另有安全限制。

本仓库提供源码变更，源码压缩包不包含游戏素材和完整运行环境。旧版 `Import.cmd` 等安装器属于此前版本，不作为本测试版的安装方式；请使用完整本地测试包。本版本不提供开服部署包。

源码清单与上游基底见 `mod/install-manifest.json`、`mod/compatibility.json`，变更见 `mod/changes.patch`。本项目代码遵循 [GPL-3.0-or-later](LICENSE)；游戏及其他素材版权归原权利人所有，不用于商业用途。
