# 酒馆英雄策略

独立工坊包 `hero-strategies`，25 位常规开局策略，以及4位仅法术模组启用时开放的策略。齐恩瓦拉暂不实装。不依赖血魔模组。

需要本仓库的英雄技能宿主扩展。仅复制此目录到没有该扩展的旧上游，不会实现主动技能；请一起移植宿主扩展，不能用整份引擎文件覆盖其他模组。

启用本包后，从原开局策略选择界面选取英雄。右侧策略效果区域出现「英雄技能」：点击直接使用；曲奇和玛维先进入点选模式，点中目标立即生效，不再二次确认。长按（手机）或悬停／右键（桌面）查看效果，悬浮说明只显示技能名和效果。被动技能无费用图标，点击查看说明。所有英雄的发现均复用调度中心的精锐奖励卡牌界面，首次点击查看、再次点击确认，费林依次发现6／4／2阶。冷却、锁定奖励与进度随服务器状态同步。取消点选不扣费。

策略数据由 `node tools/build-hero-strategies.mjs` 生成到本目录，不修改 `data/*.json`。初始生命值范围 10–30，按用户于2026-10-15确认的试玩调整分配。

规则以本次用户确认的移植方案为准，并非声称与某个炉石补丁完全一致：炎替代龙，远见替代海盗，最高盟约替代鱼人；穆克拉赠送随身身份牌；短航线赠送1阶装备；塞纳留斯每次支付3资金增加后续每轮1资金。发现按干员种类等概率，库存只影响候选资格。

生成副本：杰弗里斯、挖宝、沃恩、希尔瓦娜斯和苔丝阵容来源不扣共享干员池；正常商店补位遵循原商店规则。费林选择时预留副本，到达等级后交付，淘汰时归还。以上卡池规则为当前用户确认版本，特殊原版机制未核实处不标作官方结论。

[ASSUMED] 未操作的发现奖励在备战结束时选取第一个仍合法候选；无候选则取消该次选择。锁定奖励遇到空间不足保留在锁定区，下次回合开始或升级时重试。塔姆辛同攻击力时按战斗初始单位顺序取第一名，转移值取首次被击杀前的攻击力和生命上限。机器人备战结束前通过同一校验入口尝试一次技能；指定技能优先选择可用商店目标，航线默认选3轮，发现默认选首个合法候选。

0.1.2 新增泰瑟兰·血望者、荷利戴医生、尤格-萨隆：每第三张购买的法术免费；每轮1资金获得随机法术；第3轮起每轮开始随机施放法术。依据本地 HearthstoneJSON zhCN 卡牌快照（英雄技能 dbfId 105432 / 110472 / 122958）。[ASSUMED] 移植血量暂定28/26/24；随机来源为当前商店等级以内、有库存、已实现的普通法术，按种类等概率；尤格目标从己方持有干员中随机选择，无目标或效果拒绝时不生效，不退成手牌。自动施放不占整备区，不消耗装备位，不计购买次数。荷利戴获得实体卡占库存；满位或无候选时不扣费。

当前宿主以本局 `spellShop: separate` 行为声明开启三位策略；前端列表、服务端选取和运行时技能都检查开关。未装或未启用法术包，保持26位。不会自动装载法术或血魔包。另一份 `spell-shop-upstream` 是独立0.2.6宿主，须按其接口另行移植和验证，不能把本目录当成通用插件直接覆盖它。

头像安装：先执行 `node tools/fetch-hero-portraits.mjs`，再执行 `node tools/build-hero-strategies.mjs`。使用 [HearthstoneJSON](https://hearthstonejson.com/docs/images.html) 的英雄专用裁切头像，原始英雄卡ID见 `tools/hero-portraits.mjs`，不使用皮肤。`pack.json.art.bands` 同时供开局卡片、局内策略效果和右侧技能按钮使用。图片下载到被 Git 忽略的 `assets/art/`，不进入源码提交；复制试玩包时需连同本地 assets 目录复制。游戏美术版权归暴雪；代码许可证 GPL-3.0-or-later，保持非商业用途。

0.1.3 技能按钮改为圆形，使用对应酒馆战棋英雄技能原画。运行 node tools/fetch-hero-power-art.mjs 下载本地素材，随后重新生成策略包。主动技能显示费用，可用时绿光，已使用或冷却时变暗；被动技能始终可点开说明。点击圆形入口展开面板，选择目标及确认操作沿用原流程。

0.1.4 苔丝改为每轮按座位顺序自动轮换存活且未离队的队友，是否使用技能均不影响轮换。首轮从座位最靠前的其他队友开始；本轮来源固定，断线但仍参战的队友保留。来源本轮淘汰或离队时技能停用，下轮轮换时跳过。无队友或来源上一轮阵容为空时不可发动且不扣费。按钮下方及详情显示本轮队友。

新增斯卡布斯·刀油（间谍探查）：相同轮换规则，每轮2资金，从本轮队友上一轮出战阵容中发现普通原始版复制。按干员种类去重等概率，最多3个选项；不足3种时展示全部。沿用复制规则，不检查或消耗卡池，不受商店等级限制。[ASSUMED] 初始血量28。来源为本地HearthstoneJSON快照 BG21_HERO_010 / BG21_HERO_010p，队友阵容替代下一位对手由用户于2026-10-15确认。

0.1.5 用户确认诺兹多姆每轮获得的免费刷新可累计并跨回合保留。每轮开始增加1次，同轮重复事件不重复发放，使用普通刷新时优先消耗该次数。技能面板显示累计剩余次数。

0.1.6 锁定提示：整备区旁新增常驻锁定区，玛维锁定的干员/装备和费林预选干员显示图标、名称、来源及解锁条件；满足条件但未发放时显示等待发放。点击可查看资料，不会使用或领取。原技能面板使用相同的倒计时描述。公共组件不依赖策略/法术开关；后续两个模组合并时可分别按开关贡献锁定条目。

0.1.7 按用户编辑表简化文案并动态显示进度，费用使用按钮图标。霍格增加奇迹、投资人；狂风之翼仅法术模组启用时开放，短航线获得消耗1资金的普通法术。希尔瓦娜斯每次阵亡均增加候选票，按票加权、选项不重复。退场仅指阵亡，冰龙仍在休整期结束冻结。

锁定统一占用普通整备区格子，允许挪位置，不能部署、出售、使用、销毁或参与合成；玛维无空位时不扣费，费林也实际占格。独立锁定区已删除，卡片显示锁标，详情显示解锁条件。解锁后正常合成并保持库存记账；此前独立锁定区说明由本版替代。
