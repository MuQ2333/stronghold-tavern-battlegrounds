# dmg-board · 伤害看板（结算页）

一局打完，结算屏给每人一张卡（七项统计）；**这张看板把同一份数按「造成伤害」排成一张表**，一眼看出谁打了多少 ——
外加卡上放不下的那几项（未击倒 / 损失生命 / 刷新次数 / 完美作战）。

**数据只有一个来源：引擎自己的对局结算 `m.result`**（`shared/protocol.js` 的 S2C 类型，`server/match/results.js`
组装）。看板**不重算、不猜测、不碰对局**：引擎说什么就画什么，没有数据时整块不渲染（一个空表会被读成「引擎没算伤害」）。

## 它显示什么

挂载点 `screen.result.footer`（结算屏底部横条）。表按**造成伤害**降序；第一行标金色名次、绿色名字；
「造成伤害」那一列带一条按最大值归一的比例条；`未击倒` / `损失生命` 大于 0 的行标琥珀色。

列（**只画这一局真的带了的键**，缺键不画）：造成伤害 · 领袖伤害 · 击倒敌人 · 未击倒 · 损失生命 · 晋升次数 ·
配发装备 · 盟约层数 · 刷新次数 · 完美作战 · 消耗资金。数字按万位短写（`5.2万`）。

## 什么时候显示（这条要看清楚）

`screen.result.footer` 是**固定浮层**（管理器 `docs/WORKSHOP.md` §1.9.3：挂一次就一直在，与当前在哪个界面无关），
所以「什么时候画」由面板自己判：

- **页面上有一个活的结算屏**（`.screen.result`）才画；返回大厅 / 标题屏 → 立刻整块不渲染；
- **统计页浮层（`.st`）开着时一律不画** —— 统计页里能翻出对局记录的重看，那也是 `.screen.result`，
  但那不是本局的数，而面板拿不到那条记录（管理器给面板的注入面里没有 stats 记录）。宁可什么都不显示，
  也不显示上一局的数；
- 数据留一份在面板里：结算屏重进 / 切回来还在（同一局不重发 `m.result`）。

## 边界（先知道再装）

- **是结算页的看板，不是实时伤害表。** 实时那半在引擎里是**客户端→服务端**的上报（`b.progress` 是 C2S，
  由场上的权威客户端报告），面板订阅不到；服务端广播里也没有逐人实时伤害。所以本包只做结算那一张表。
- **统计页里不显示**（原因见上）。
- **不改任何东西**：注入面只有 `host` 与 `net.on('m.result')`（只读订阅），没有 store / 对局对象，
  面板连一次 `send` 都没有。
- 与引擎自带的结算卡**并存**：卡片仍然七项一行行摆着，这里只是多一张排好序的总表。
