# 局内文字聊天（房内气泡）

作者：**纸鸢干机**（不是我做的 —— 能力来自 Paper-Yuan 0.2.4 的灵感，实现在 Forge 的 mod 表面上）

## 它做什么

对局里左下角一个输入框，回车把一句话送到**同一个房间里、同样装了这个包**的客户端，
收到的一方在自己屏幕上以气泡显示，4 秒后淡出。

## 走的是哪条路

引擎自己的**包命名空间通道** `pack.msg`：

- 上行 `ctx.net.send('say', {...})`，下行 `ctx.net.on('say', fn)`；
- 线上类型 `pack.msg` **由引擎定义**，通道名 `say` 由本包声明（线上拼成 `chat-bubble.say`）；
- 引擎**不解释** `data` 的语义，只做三件事：校验形状、限流、把字节送到该到的地方。

所以**没有发明任何协议类型**：`shared/protocol.js` 里 `pack.msg` 同时挂在 C2S 与 S2C 两张表上，
`b.*` 那条边界一个字没动。这正是 `docs/MOD-SURFACE.md` 「刻意不是表面的东西」里要求的做法 ——
原文：「包不能发明 S2C/C2S 类型。包自己的通道走 `pack.msg`，类型名由引擎定」。

额度（引擎定，包改不了）：单条 `data` ≤ 4096 字节、每会话 5 条/秒、突发 20 条。

## 重要边界（必读）

**这不是引擎的房内聊天。** `room.chat` / `room.quickMsg` 是**产品功能**
（`docs/META.md` §1.6–§1.8），由引擎自己实现、**不对包开放**。本包是包自己的通道，因此：

1. **只有装了本包的人互相看得见** —— 没装的人看到的对局与今天逐字相同；
2. **跨包不互通** —— 另一个聊天包收不到本包的消息；
3. **名字没有身份校验** —— 显示的名字取自消息里对方自称的 `name` 字段。引擎不校验 `data`，
   本包也没有校验的余地（面板拿不到会话注册表）。真要防冒名，需要引擎给一格
   「消息附会话身份」的表面（按「加一格表面」六步走），那是引擎改动。

## 安全

- 一律 `textContent` 写文本，**绝不**拼 `innerHTML` —— 别人发来的字符串永远只是文本；
- 发送侧按码点截断到 120 字，与引擎「截断而非拒绝」同一口径；
- 客户端自限 250ms/条（引擎限 5 条/秒，这里留余量），不试图绕过限流。
