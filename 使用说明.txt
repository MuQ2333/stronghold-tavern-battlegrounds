卫戍协议：酒馆战棋模组　使用说明
模组版本：0.2.3
适配游戏：原版卫戍协议 v0.3.0
运行环境：Node.js 22 或以上；Windows / Linux

一、这个包是什么

这是模组安装包，需要先准备一份能正常启动的原版游戏。
包含酒馆法术、30位英雄策略、鲍勃中文原声及相关操作界面。
模组图片和录音已经包含在Full.zip中；原游戏及其原生素材需自行准备。
视频里的私人整合测试服可能含有额外聊天、名片、换装等功能，这些不包含在本基础包中。

二、安装

1. 完整解压Full.zip到游戏目录以外；不要只拿出一个脚本运行。
   使用说明、Import.cmd、install.sh、mod和scripts应位于同一层。
2. 停止游戏服务。
3. Windows：双击Import.cmd，输入游戏目录并回车。
   Linux：在解压后的模组目录执行：
   bash install.sh "/srv/Stronghold-Protocol"
4. 游戏目录指含package.json、server、public的那一层，不是模组包目录。
5. 出现“导入完成”后，按原来的方式开服。监听地址和端口仍使用你自己的部署配置。
6. 玩家访问服务器网页即可，不需要每位玩家再安装一份。更新后刷新网页。

GitHub的Source code ZIP / Download ZIP是源码，不含图片和录音。
请下载Tavern-Battlegrounds-0.2.3-Full.zip。网盘也使用同名完整包。
安装不会自动下载原游戏、安装依赖、修改端口或关闭已有进程。

三、功能开关

进入房间后：
- “酒馆法术”“酒馆英雄策略”默认开启，由房主在开局前分别设置。
- 修改玩法开关后，其他玩家需要重新准备；对局开始后不能改该局开关。
- “鲍勃商店老板（仅自己）”默认关闭，每位玩家自行开启。
- 开启鲍勃后，点击头像可屏蔽或取消屏蔽；没有单独的教学提示开关。

四、法术和英雄技能

- 局外点击“法术预览”，按等阶筛选、搜索并查看法术效果。
- 调度中心有独立法术商品栏。购买后的法术进入整备区，拖到合法目标施放。
- 不指定干员的法术：拖到战场普通格，不要求场上已有干员。
- 指定干员的法术：拖到满足条件的目标干员。
- 支援：拖到空闲地面格放置标记，战斗开始时部署星熊。
- 新增英雄的主动技能使用对应按钮操作。效果、费用和次数以游戏内说明为准。
- 单人模式中，需要其他玩家的策略不会进入可选池。

五、校验、卸载和升级

安装后校验（把路径换成自己的游戏目录）：
node install.mjs --check "/srv/Stronghold-Protocol"

卸载前先停服：
- Windows：双击Uninstall.cmd并输入游戏目录。
- Linux：bash uninstall.sh "/srv/Stronghold-Protocol"

安装前原文件保存在游戏目录的.tavern-mod-backup。请保留备份和下载包。
升级模组时先用旧版工具卸载，再安装新版，不能直接叠装。
从0.1.x升级时，卸载后先把原游戏更新到匹配的0.3.0，再安装本版。
若安装后的文件又被其他修改覆盖，卸载会停止并指出路径；先核对改动，不要强行覆盖。

本版支持官方0.3.0完整包、精简包及对应源码副本。自动安装只写运行文件与模组素材，不改游戏目录中的开发文档、测试及维护工具。

六、常见问题

- 找不到Node：检查node --version，确保当前终端或面板能找到Node.js 22+。
- 旧版报docs/ARCHITECTURE.md等开发资料不一致：换用0.2.3完整模组包重试；未导入成功时无需卸载或重新下载原游戏。
- 运行文件与适配上游不一致：确认是指定版本的原版游戏；其他分支和模组可能需要单独适配。
- 素材缺失：重新完整解压Full.zip，不要使用GitHub自动生成的源码ZIP。
- 其他设备连不上：检查主机监听地址、端口和平台映射；对方设备上的127.0.0.1不是服务器。
- 手机界面异常：反馈时注明手机、浏览器、缩放比例、是否全屏，并附截图。
